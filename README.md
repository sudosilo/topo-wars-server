Topo Wars Server

Topo Wars Server is the backend for the Topo Wars game. It is for players who battle friends.

It keeps the real copy of every two player battle and replays each turn with the same rules the game uses. Players can join a battle by code and keep playing between turns. It can send turn notifications. The root address has no home page, so it returns a not found page by design.

Live at topo-wars-server.vercel.app

Latest change. 2026-10-03, v2026.10.03. Added tanks, mines, a chinook, and grenade splash damage. Added a commander aura. The battle rules were synced with the game several times.
