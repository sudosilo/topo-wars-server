Topo Wars Server

Topo Wars Server is the backend for the Topo Wars game. It is for players who battle friends.

It keeps the real copy of every two player battle and replays each turn with the same rules the game uses. Players can join a battle by code and keep playing between turns. It can send turn notifications. The root address shows a status page.

Live at topo-wars-server.vercel.app

Latest change. 2026-11-24, v2026.11.24. The root address now shows a status page with a link to the game instead of a not found page.
